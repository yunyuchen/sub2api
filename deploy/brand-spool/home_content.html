一个地址，一把 key，接上公司的 AI 模型。

spool 是公司内部的 AI 网关。公司买的上游账号集中在这里，对外只有一个地址。你建一把自己的 key，改两个环境变量，用量按人记。

BASE URL以 /keys 页显示的为准末尾不带斜杠
$https://spool.corp.internal

这一页没有复制按钮。点一下地址或下面任意一行命令，整行会自动选中，再按 Cmd-C。

  • 模型Claude · GPT-Codex · Gemini · Antigravity
  • 协议兼容 OpenAI 和 Anthropic 两套协议，对应的客户端直接能用
  • 用量按人统计。额度用完直接报错，不降级、不静默截断

三步接入

/login → /keys → shell 01 · ACCESS
1

登录

/login

不开放自助注册，账号由管理员创建。拿到账号后从这里登录。

2

建 key

/keys

分组必填，它决定这把 key 能看到哪些模型。一把 key 一个分组。

3

改两个环境变量

BASE_URL + KEY

其他都不用动。用哪一对变量看客户端，和分组无关。

环境变量

两个变量，代码不用动 02 · CONFIG
Claude CodeANTHROPIC
$ export ANTHROPIC_BASE_URL=https://spool.corp.internal$ export ANTHROPIC_AUTH_TOKEN=<你的 key>
Codex / OpenAI SDKOPENAI
$ export OPENAI_BASE_URL=https://spool.corp.internal/v1$ export OPENAI_API_KEY=<你的 key>
自检GET /v1/models
$ curl -s $OPENAI_BASE_URL/models -H "Authorization: Bearer $OPENAI_API_KEY"# 回一个模型列表就算接上了。401 是 key 不对；403 / 429 / 503 / 404 见下面的故障码。# 只配了 ANTHROPIC_* 的：地址换成 $ANTHROPIC_BASE_URL/v1/models，key 用 $ANTHROPIC_AUTH_TOKEN。

试验性

  • Antigravity

随时可能下线，不要用在正式流程里。

真正的清单是 GET /v1/models 的返回。能看到哪些模型，由你这把 key 的分组决定，不是公司全部模型。model id 按返回原样填，不要手写。看不到的模型，说明不在你分组的白名单里。

报错怎么读

先看 body 里的 code，别只看状态码 04 · FAULT CODES
HTTPBODY CODESTATEACTION
429 QUOTA_EXHAUSTEDUSAGE_LIMIT_EXCEEDEDinsufficient_quota（Codex 路径） HALT 额度用完。重试没用，找管理员加额度。
429 USER_RPM_EXCEEDEDGROUP_RPM_EXCEEDED BACKOFF 请求太快，触发限速。退避几秒重试。
403 INSUFFICIENT_BALANCE HALT 余额不足。找管理员。
503 无 code BACKOFF 暂时没有可用账号能跑这个模型。退避重试；一直 503 就在群里反馈。
404 not available for this group CONFIG 模型不在你分组的白名单里。换分组，或找管理员加。

额度用完不降级、不静默截断——你会看到一条明确的报错。401 只有一个意思：key 不对。

key 丢了不用重建：在 /keys 列表里随时能完整复制回来，不是只显示一次。用量在控制台能看到；不想登录，就去 /key-usage 输 key 查自己那一份。

使用规则

三条，没有例外 05 · RULES

key 不要提交到仓库，也不要发到群里。

按用途分开建几把 key，泄漏时只吊销对应的那一把；能登录你账号的人就能拿到你所有的 key。

跑批量前群里说一声。

错开高峰；CI 单独建一把 key，不要和你平时用的那把混用。

额度按人分配，不够用提前找管理员。

不要借用别人的 key，用量会记在他名下。
