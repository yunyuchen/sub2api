## 13. 昵称默认展示 + 假名改「第 N 位」（用户 2026-09-12 晚反馈）

本节是第 12 节之后的第四轮增量，来源是用户原话「用户名字要写，不要写用户 #4 这样…只要显示用户的昵称就可以了」。四条口径：
`leaderboard_named_participation` 的**语义不变**但默认值改为 `true` 并回填既有用户；他人的假名从「用户 #N」改为「第 N 位」（英文 `Row N`，N 仍是 Ordinal 而不是 user_id）；本人行与本人相关的卡片有 username 就显示本人的 username（仍带「你」标记），没有才显示「当前用户」；username 校验规则与匿名档规则一律不动。
它取代 3.1–3.8 的「默认关闭 / 自选实名」口径与 11.26、12.9 里的「用户 #Ordinal」字面量；第 1–12 节的其余内容不受影响。
