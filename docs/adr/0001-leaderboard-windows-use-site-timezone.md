# 排行榜窗口按站点时区计算，而不是查看者时区

管理端仪表盘的日期范围按查看者浏览器时区解析（`parseTimeRange` 接收 `timezone` 参数），排行榜刻意不沿用这一做法：今日 / 本周 / 本月的边界一律用 `backend/internal/pkg/timezone` 的站点级 `StartOfDay` / `StartOfWeek`（周一起算）/ `StartOfMonth` 计算。排行榜的前提是所有人在同一时刻看到同一张榜，按查看者时区算会让两个人看到不同的「今日榜」，也让快照无法共享；代价是与仪表盘的「今日」口径可能相差一个时区偏移，页面上标注计算时区来说明。

## Considered Options

- 按查看者时区，与仪表盘一致：否决，榜单不再是公共对象，且快照要按时区分裂。
- 让管理员单独配置一个「排行榜时区」：否决，站点时区已经存在，再加一个只会制造第二套口径。
